# Кори курсӣ: Коркарди веблоиҳаи фурӯши чиптаҳо барои қатораҳои байнишаҳрӣ

- **Фан:** Технология ва забонҳои интернет-барномасозӣ
- **Мавзӯъ:** Коркарди веблоиҳаи фурӯши чиптаҳо барои қатораҳои байнишаҳрӣ
- **Сол:** 2026-2027
- **Стек:** PHP 8+, MySQL (MariaDB), Tailwind CSS, Vanilla JS, HTML5 Print Engine

---

## 🚀 Хусусиятҳои асосӣ (Талаботи ТЗ)

1. **Интихоби ҷой дар нақшаи вагон (Интерактивӣ):**
   - Нақшаи графикии вагонҳои СВ / Люкс, Купе ва Плацкарт (бо ҷойҳои поёнӣ, болоӣ ва паҳлӯӣ).
   - Рангҳои ҷойҳо: 
     - **Хокистарӣ/Сабз:** Ҷойи холӣ ва дастрас.
     - **Сурх:** Ҷойи фурӯхташуда (ғайрифаъол).
     - **Зард/Норанҷӣ:** Ҷойи бандшуда (15 дақиқа).
     - **Кабуди дурахшон (Cyan):** Ҷойи интихобшудаи мусофир.
2. **Бандкунии 15-дақиқагӣ бо таймери зинда:**
   - Мувофиқи талабот: *"Ҷой ба муддати 15 дақиқа то пардохт банд карда мешавад; агар пардохт нашавад, ҷой холӣ мешавад."*
   - Ҳангоми гузаштани 15 дақиқа, системаи худкори тозакунӣ ҷойро барои дигар мусофирон озод менамояд.
3. **Нақшҳои корбарон:**
   - **Мусофир:** Ҷустуҷӯи қатнавҳо, интихоби вагон ва ҷой, хариди онлайн, чопи чипта ва баргардонидани он.
   - **Кассир:** Фурӯши фаврии чипта дар касса, баргардонидани чипта ва ҳисоботи басти кории рӯзона.
   - **Маъмур (Admin):** Идораи пурраи истгоҳҳо, хатсайрҳо, қатораҳо, вагонҳо, қатнавҳо, нархгузорӣ ва таҳлили даромад.
4. **Чопи чипта дар PDF:**
   - Формати зебои Boarding Pass бо нишони давлатӣ, QR-код, штрих-код ва маълумоти пурраи сафар.
5. **Баргардонидани чипта:**
   - Дар як пахши тугма бо озод шудани худкори ҷой дар нақшаи вагон.

## 🛠 Роҳнамои насб ва ба кор даровардан

### 1. Танзими Пойгоҳи Додаҳо (phpMyAdmin):
1. Барномаи **XAMPP** ё **OpenServer**-ро фаъол созед (Apache ва MySQL).
2. Браузерро кушоед ва ба суроғаи `http://localhost/phpmyadmin` ворид шавед.
3. Бахши **«Импорт» (Import)**-ро пахш намуда, файли `database.sql`-ро интихоб кунед ва тугмаи **«Вперед / Go»**-ро пахш намоед. 
   *(Пойгоҳи додаҳо бо номи `train_tickets_db` ва ҳамаи маълумотҳои намунавӣ худкор сохта мешавад).*

### 2. Ҷойгиркунии файлҳо:
- Папкаи `train_ticket_system`-ро ба папкаи веб-сервер нусхабардорӣ кунед:
  - Барои XAMPP: `C:\xampp\htdocs\train_ticket_system`
  - Барои OpenServer: `...\domains\train_ticket_system`

### 3. Кушодани лоиҳа:
Дар браузер суроғаи зеринро ворид намоед:
```
http://localhost/train_ticket_system/
```
